🔤 重點單字
  • der Pullover：毛衣（陽性名詞，複數同形）
  • kaufen：買（規則動詞，Perfekt 用 haben）
  • gestern：昨天
  • die Stadt：城市（陰性名詞）

📚 文法解析
1. 現在完成式（Perfekt mit haben）
結構：haben（第二位）+ … + Partizip II（句尾）
德語談論過去的事，口語最常用 Perfekt：助動詞 haben 變位放第二位，過去分詞放句尾。
　例：Ich habe ein Buch gelesen.（我讀了一本書。）

2. 第四格受格（Akkusativ）
結構：動詞 + einen（陽性）/ eine / ein + 名詞
Pullover 是陽性名詞，當直接受詞時不定冠詞 ein 變成 einen，形容詞詞尾也跟著變成 -en。
　例：Ich suche einen Job.（我在找工作。）

💡 講到昨天或上週做的事，德國人口語幾乎都用 Perfekt 而不是 Präteritum。
